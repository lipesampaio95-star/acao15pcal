# ⚖️ Sistema de Cálculo PC/AL

Sistema web desenvolvido em **Python + Streamlit** para automatizar o cálculo de diferenças remuneratórias por classe funcional da Polícia Civil de Alagoas (PC/AL).

O sistema cruza automaticamente:
- 📄 **Ficha Financeira (PDF)**
- 📄 **Fichas Cadastrais / Funcionais (PDF)**

Reconstruindo a linha do tempo da carreira do servidor e calculando diferenças com base na progressão de classes.

---

## 🚀 Funcionalidades

- Upload manual de Ficha Financeira e Fichas Cadastrais
- Leitura automática de:
  - Subsídio mensal
  - Ano de referência
  - Datas de promoção
  - Classe funcional (A a G)
- Reconstrução automática da linha do tempo funcional
- Cálculo de diferenças salariais (15% por classe)
- Dashboard com:
  - Tabela detalhada
  - Gráfico comparativo Pago x Devido
- Controle manual por botões:
  - ▶️ Executar Cálculo
  - 🗑️ Limpar Dados
