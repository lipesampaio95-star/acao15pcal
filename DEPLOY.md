# 🚀 Deploy no Streamlit Cloud

Para publicar este app no [Streamlit Cloud](https://streamlit.io/cloud):

---

## 📦 Estrutura do Repositório

```
📁 calculadora-pcal/
├── app_promocao_manual.py
├── requirements.txt
├── README.md
├── .gitignore
```

---

## 📝 Passos

1. Faça login em [https://streamlit.io/cloud](https://streamlit.io/cloud)
2. Clique em **"New app"**
3. Conecte seu GitHub e escolha o repositório com os arquivos acima
4. Defina `app_promocao_manual.py` como arquivo principal
5. Clique em **Deploy**

O app será publicado com uma URL exclusiva.

---

## 🌐 Exemplo de URL

```
https://nomeusuario.streamlit.app
```
